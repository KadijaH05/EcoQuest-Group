# EcoQuest

Hello! This is the **EcoQuest** group.

EcoQuest was created by **Destiny Dada** and **Kadija Hien** to help keep neighborhoods and communities clean while getting paid.

## About EcoQuest

EcoQuest is an app that encourages people to pick up trash in their communities and neighborhoods. By participating, users can help create cleaner and healthier neighborhoods while earning rewards.
